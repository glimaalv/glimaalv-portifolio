## 📖 Sobre o Projeto

Este repositório contém o código do meu portfólio pessoal, desenvolvido como um desafio prático durante o **Bootcamp Front End - Santander** na plataforma DIO. 

O projeto foi construído para ser uma base sólida, focada em boas práticas de desenvolvimento web e design de interfaces. O site serve como um cartão de visitas digital e está em constante evolução.

## 🚀 Tecnologias e Práticas Utilizadas

O desenvolvimento focou em performance, acessibilidade e facilidade de manutenção:

*   **HTML Semântico & SEO:** Estruturação correta das tags para melhor indexação nos motores de busca e acessibilidade.
*   **CSS3 Moderno:** 
    *   Uso intensivo de variáveis nativas (Custom Properties) para controle e manutenção de cores e temas.
    *   Alternância de temas (Dark/Light mode) facilitada.
*   **JavaScript:** Lógica de manipulação para alternância de tema e uso de armazenamento em cache local (Local Storage) para que a preferência de tema do usuário seja mantida em acessos futuros.
*   **UI/UX & Design:**
    *   Prototipação completa e planejamento visual realizados no **Figma**.
    *   Layout 100% responsivo construído com a abordagem **Mobile First** e controle preciso via *Media Queries*.

## ⚙️ Infraestrutura e Deploy

A infraestrutura foi pensada para automação e profissionalismo:

*   **Domínio Próprio:** Compra e configuração de domínio customizado associado ao meu usuário, garantindo um acesso mais amigável, direto e profissional à página.
*   **CI/CD com GitHub Actions:** Pipeline de deploy totalmente automatizada. A cada atualização no repositório, o GitHub Actions realiza o envio dos arquivos via **FTP** diretamente para o servidor web, sem a necessidade de intervenção manual.

## 🚧 Status do Projeto

> ⚠️ **Status:** Em Desenvolvimento (Base Inicial Concluída)

O site ainda não está 100% pronto. A versão atual atua como uma fundação arquitetural para o projeto. O objetivo inicial era estabelecer a estrutura e os processos de deploy. Em breve, novos incrementos, projetos reais e evoluções de design serão adicionados à página.
